# kdu-lost-found-system

A simple, secure web application for reporting, managing, and reclaiming lost & found items at KDU. This repository contains the code and documentation for a system that lets users report found items, search for lost items, and claim possessions — with an admin workflow for verification and release.

## Features

- Report found items with photos and optional location details
- Search and filter lost/found items by category, date, location, keywords
- Secure claim workflow (claim request, admin verification, release)
- Admin dashboard to manage items, claims, and users
- Email (or in-app) notifications for status updates
- Optional attachments (images) with basic validation
- Audit history for item reports and claim actions
