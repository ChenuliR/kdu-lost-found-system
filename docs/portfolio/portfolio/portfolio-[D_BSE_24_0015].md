## 2. Project Overview

The Campus Lost & Found Portal is a web-based system designed to help students and staff report, browse, search and reclaim items lost or found on campus. It provides a centralized place to view lost-and-found posts and submit claim requests. Administrators can access an admin dashboard to review claim requests and monitor key system information.
 
The project aims to make the lost-and-found process more organized and accessible than relying on informal methods such as noticeboards or social media posts.

## 5. Challenges and How I Addressed Them

### Adapting the UI to Client Feedback

**Challenge**: The initial navigation layout did not match the client's preferred placement.

**How I addressed it:** I revised the design by moving the navigation bar from the top-right to the left side, then presented the updated version to the client for review.

### Incorporating Dark Mode

**Challenge**: Dark mode was requested after the initial UI design had been prepared.

**How I addressed it:** I updated the interface design and implemented the dark-mode change, then demonstrated the revised interface to the client.

### Representing Different User Roles

**Challenge**: Student/staff users and administrators have different profile-menu options and permissions. For example, the admin portal is available to administrators but not to normal student/staff users.

**How I addressed it:** I created separate user journey flows for student/staff profile interactions and the admin profile/dashboard flow, making the differences in available options clearer.

### Documenting the Complete User Journey

**Challenge**: The system contains several connected activities, including registration, login, browsing, post management, claim submission, claim review and logout.

**How I addressed it:** I separated the system into focused user journey flowcharts and revised the login flow to represent the actual registration and login behaviour. This made each journey easier to understand and review.
