## 2. Project Overview

The Campus Lost & Found Portal is a web-based application designed to help university students and staff report, search for, and recover lost belongings. It provides a centralized platform for managing lost and found item listings, submitting claim requests, tracking claim statuses, and allowing administrators to review claims and manage listings.

The system was developed using TypeScript, CSS, JavaScript, and Supabase. The project aims to make the process of finding and returning lost belongings more organized, accessible, and efficient within the university community.
